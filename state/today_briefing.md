# Daily AI Recruitment Briefing — 25 July 2026

## Claude & Anthropic in TA

- **Anthropic launched Claude Opus 5**, adding a low/medium/high "effort" dial that lets teams trade cost for capability on each call, plus long-horizon agents that can run for hours on a task — at the same $5/$25 per-million pricing as Opus 4.8. For TA, the cost dial and cheaper autonomy make agentic sourcing and high-volume screening materially more affordable to run at scale; pilot it against your current screening spend before renewing per-seat AI tooling. ([Fortune](https://fortune.com/2026/07/24/anthropic-debuts-claude-opus-5-with-feature-that-lets-users-toggle-between-cost-and-capability/)) (24 July 2026)
- **Claude Opus 5 also went generally available in Microsoft Foundry** the same day, giving Azure-standardized enterprises a governed path to run the new model inside existing security and compliance boundaries. If your org routes AI through Azure, your recruiting-agent build no longer needs a separate Anthropic procurement track. ([Microsoft](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/claude-opus-5-is-available-today-in-microsoft-foundry/4535068)) (24 July 2026)

## AI in Recruitment — What's New

- **RocketReach launched an MCP Server** that gives AI assistants — including Claude — direct, real-time access to its database of 700M+ verified contacts and 60M companies, so recruiters can prospect and source candidates from inside a chat assistant rather than the RocketReach UI. It extends the "MCP-into-the-sourcing-stack" pattern to contact data; before wiring it in, confirm how candidate PII is scoped and logged when an assistant queries it. ([PR Newswire](https://www.prnewswire.com/news-releases/rocketreach-launches-rocketreach-mcp-giving-ai-assistants-direct-access-to-700m-verified-contacts-302832384.html)) (22 July 2026)

**Bottom line:** Cheaper, longer-running Claude agents plus MCP-connected sourcing data mean agentic screening and prospecting are getting both more capable and more directly embedded in recruiter workflows — adopt the capability, but pair it with the emerging spend, entitlement, and PII-scoping controls before you scale it.
