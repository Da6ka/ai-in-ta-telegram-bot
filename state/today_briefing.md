## Claude & Anthropic in TA
- Anthropic brought **Claude Mythos 5 — its frontier security model, previously reserved for vetted defenders through Project Glasswing — to Claude Security**, which now connects to a GitHub repo, traces data flows across files, and returns vulnerabilities tagged with a CWE category, confidence/severity ratings, and a suggested patch ([MarkTechPost](https://www.marktechpost.com/2026/08/21/anthropic-brings-claude-mythos-5-to-claude-security/), 21 August 2026). As TA teams stand up Claude-based sourcing/screening agents and ATS integrations that touch candidate PII, this is the kind of automated code-vulnerability control to wire into that build pipeline before agents go near applicant data.
