# Daily AI Recruitment Briefing — 23 August 2026

## Claude & Anthropic in TA
- Anthropic moved computer use, a new **browser use tool**, the Skills API, and the Files API to general availability on the Claude Platform — letting agents operate software and websites that have no API, act on specific page elements, and return finished files with 20–40% fewer round trips ([Claude by Anthropic](https://claude.com/blog/computer-use-skills-api-files-api), 20 August 2026). This is the building block for TA agents that navigate an ATS UI or job boards directly; if you're piloting Claude in sourcing or screening, this is the layer that turns a chat assistant into something that actually clicks through your stack.
- Claude's Gmail and Google Drive connectors gained **write actions** — sending, replying to, and forwarding email, plus sharing, moving, and trashing files — with approval on by default but disable-able on paid/admin-enabled plans ([PCQuest](https://www.pcquest.com/artificial-intelligence/claude-can-now-do-more-with-access-to-gmail-and-google-drive-12399281), 19 August 2026). For recruiters running candidate outreach through Claude, revisit your approval gates before turning off confirmation: an agent that sends on its own is convenient until it emails the wrong candidate list.

## AI in Recruitment — What's New
- AI-assisted candidate cheating — real-time answer coaching, deepfake video, and fabricated credentials — is now widespread enough that firms like Google, McKinsey, and Cisco are reverting to in-person interviews, per a Forbes analysis of the emerging hiring-integrity crisis ([Forbes](https://www.forbes.com/sites/karadennison/2026/08/17/the-rise-of-ai-cheating-culture-and-the-hiring-crisis-it-left-behind/), 17 August 2026). Pressure-test your interview process for fraud exposure now — especially remote technical loops — before a bad hire clears a compromised screen.

**Bottom line:** Anthropic just shipped the agent primitives (browser control, write-enabled connectors) that make autonomous TA workflows real — but the same automation wave is arming candidates to game your funnel, so pair every new agent you deploy with a hardened, fraud-aware verification step.
